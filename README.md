## Changes in 1.1.0
- Moved from brand-inc.co.za to GitHub Pages; removed Brand-Inc references; contact is now pvvuurenza@gmail.com.

## Updating
Edit the HTML files, bump `VERSION`, commit and push to `main`; GitHub Pages republishes automatically.

## Limitations
- Pages are `noindex`. Google will still show an "unverified app" warning on the Allow screen (expected for a private app).
