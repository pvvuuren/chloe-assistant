Privacy Policy

Last updated: 13 October 2026

Who we are

Chloe Assistant is a private tool run by Paul van Vuuren (South Africa) for his own use. Contact: pvvuurenza@gmail.com.

What data it accesses

Only after the account owner signs in and grants permission, Chloe Assistant can access that Google account's Gmail messages, Google Calendar events, Google Drive files, Google Docs, Google Sheets and Google Contacts.

How the data is used

  • Only to carry out tasks the account owner asks for, such as sorting email, drafting replies, scheduling events and finding files.
  • Emails are never sent, and files are never deleted or shared, without the owner's approval.
  • Data is not sold, rented or shared with third parties, and is not used for advertising.
  • Data is not used to train general-purpose AI models.

Storage and security

Access tokens are stored on a private server controlled by the owner. Email and file content is processed only while a task runs and is not kept longer than needed for that task.

Google API Services User Data Policy

Chloe Assistant's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. To ask for any stored data to be deleted, email pvvuurenza@gmail.com.
